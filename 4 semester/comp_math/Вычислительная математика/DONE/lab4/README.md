# Лабораторная работа №4 — аппроксимация функции методом наименьших квадратов

Вариант 3: `y = 4x / (x^4 + 3)`, интервал `[-2; 0]`, шаг `h = 0.2`.

## Запуск

```bash
python main.py
```

Зависимости:

```bash
pip install matplotlib
```

`tkinter` обычно идет вместе с Python. Если его нет, установите пакет `python3-tk` или переустановите Python с поддержкой Tcl/Tk.

## Что реализовано

- GUI с вводом таблицы из 8–12 точек.
- Загрузка исходных данных из `txt/csv`.
- Обработка чисел с точкой и запятой как десятичным разделителем.
- Человекочитаемые сообщения об ошибках.
- Отсутствие ограничения длины вводимых чисел в полях GUI.
- Построение графиков исходной таблицы и аппроксимирующих функций.
- Вывод коэффициентов, меры отклонения `S`, среднеквадратического отклонения, массивов `x_i`, `y_i`, `phi(x_i)`, `epsilon_i`.
- Коэффициент корреляции Пирсона для линейной зависимости.
- Коэффициент детерминации `R^2` и текстовая оценка качества.
- Выбор лучшей аппроксимирующей функции по минимальному среднеквадратическому отклонению.
